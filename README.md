# VoyageAI - The Future of Travel Planning

VoyageAI is a visually stunning, AI-powered travel planning and experience engine built for the modern traveler. Powered by Google's Gemini API and Google Cloud.

## 🌟 Core Features
- **AI Travel Planner**: Complete itineraries, hidden gems, and recommendations generated by Gemini 2.5 Flash.
- **AI Chat Assistant**: Context-aware floating assistant to answer all your travel queries.
- **Expense Estimator**: Beautifully animated charts tracking budget across hotels, food, transport, etc.
- **Interactive Map**: Seamless Google Maps integration highlighting daily itinerary routes.
- **Responsive & Modern UI**: Glassmorphism, animations, dark mode, and a highly polished design.

## 🛠 Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4, Framer Motion
- **Backend & Auth**: Firebase Auth, Firestore
- **AI**: Gemini API (`@google/genai`)
- **Maps**: Google Maps API
- **Deployment**: Google Cloud Run (Docker)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Firebase project setup
- Google Cloud Platform account (for Gemini & Maps API keys)

### Setup Instructions

1. **Clone the repository** (or use the provided directory).
   ```bash
   cd voyage-ai
   npm install
   ```

2. **Environment Variables**
   Copy the example environment file and fill in your keys:
   ```bash
   cp .env.example .env.local
   ```
   Add your Firebase, Gemini, and Maps keys.

3. **Run Locally**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000`

## ☁️ Deployment to Google Cloud Run

We provide a production-ready `Dockerfile`.

1. **Build the container**
   ```bash
   docker build -t voyage-ai .
   ```

2. **Tag & Push to Google Artifact Registry**
   ```bash
   docker tag voyage-ai gcr.io/YOUR_PROJECT_ID/voyage-ai
   docker push gcr.io/YOUR_PROJECT_ID/voyage-ai
   ```

3. **Deploy to Cloud Run**
   ```bash
   gcloud run deploy voyage-ai --image gcr.io/YOUR_PROJECT_ID/voyage-ai --platform managed --allow-unauthenticated
   ```

## 🏗 Architecture
- `src/app`: Next.js 15 app router pages (Landing, Dashboard, Planner)
- `src/components`: Reusable UI components (Navbar, Map, ChatWidget)
- `src/lib`: Firebase and Gemini API client initializations
- `Dockerfile`: Multi-stage build for optimal Next.js production hosting
